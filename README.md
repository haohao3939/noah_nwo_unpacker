# noah_nwo_unpacker
诺亚舟nwo视频格式文件提取器
<img width="1096" height="742" alt="image" src="https://github.com/user-attachments/assets/dbedec78-ad86-4218-926d-228bb44aafa3" /><img width="1238" height="826" alt="image" src="https://github.com/user-attachments/assets/cd019843-4c62-4e5b-afb1-86c183b65bc7" />

此脚本可以将诺亚舟特有的nwo格式文件进行转换视频操作，以便观看课件视频。 

使用方法
在命令行（CMD / PowerShell）中运行 nwo2avi.exe：
# 转换单个文件（默认在同目录生成同名 .avi）
nwo2avi.exe "视频.nwo"
# 转换单个文件并指定输出路径
nwo2avi.exe "视频.nwo" "输出.avi"
# 批量转换整个文件夹中的所有 .nwo 文件
nwo2avi.exe "输入文件夹路径" "输出文件夹路径"
